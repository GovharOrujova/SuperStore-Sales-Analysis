# SuperStore-Sales-Analysis
Sales Data Analysis and Forecasting using SuperStore Dataset# 📊 SuperStore Sales Dashboard

This project presents *sales analysis and short-term forecasting* based on the *SuperStore Sales Dataset*.  
The analysis and visualizations are created entirely with *Power BI dashboards*.  

---

## 📄 Overview
The goal of this project is to analyze sales performance, visualize key metrics, and provide short-term forecasts for business insights.  

---

## 📊 Analysis
- Sales distribution by Region, Segment, and Payment Mode  
- Monthly Sales and Profit trends (2019–2020)  
- Category and Sub-Category performance  
- Sales and Profit by State (US map)  
- 15-day sales forecast  

---

## 🧠 Key Concepts Used
- *Data Cleaning & Preparation* in Power BI  
- *Data Modeling* for dashboards  
- *Data Visualization* (charts, maps, KPIs)  
- *Time Series Forecasting* using Power BI forecasting tools  

---

## 📈 Outputs
- *KPIs:* 22K Orders, 1.6M Sales, 175K Profit, Avg. Ship Time: 4 days  
- *Regional Sales:* West leads with 33% share  
- *Top-selling product groups:* Phones, Chairs, Binders  
- *Forecast results:* Peak sales between 9.4K – 10.6K
